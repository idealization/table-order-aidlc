# 통합 테스트 지침 (Integration Test Instructions)

## 목적
프론트엔드 ↔ 백엔드 ↔ SQLite 간 상호작용과 핵심 사용자 흐름을 검증합니다.

## 사전 준비
```bash
# 1. DB 시드 (최초 1회)
cd backend && npm run seed

# 2. 백엔드 실행
cd backend && npm run dev          # http://localhost:3001
```

## 통합 테스트 스크립트
핵심 흐름을 자동 검증하는 스크립트가 `backend/test-integration.sh`에 있습니다.
```bash
cd backend && bash test-integration.sh
```

## 수동 E2E 확인 (브라우저)
1. **고객 흐름**: http://localhost:5173/store/store-001/table/table-001/menu
   - 메뉴 담기 → 장바구니 → 주문하기 → 주문번호 표시 → 5초 후 메뉴 복귀 → 주문내역 확인
2. **관리자 흐름**: http://localhost:5173/admin/login (admin / admin1234)
   - 대시보드에서 신규 주문 실시간 표시(SSE) 확인 → 카드 클릭 → 상태 변경/삭제
   - 테이블 관리 → 이용 완료 → 과거 내역에서 확인
   - 메뉴 관리 → 등록/수정/삭제/이미지 업로드
