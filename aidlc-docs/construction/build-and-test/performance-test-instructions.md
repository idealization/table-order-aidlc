# 성능 테스트 지침 (Performance Test Instructions)

## 목적
실시간 주문 표시(2초 이내, NFR-1)와 다중 매장/테이블 규모를 검증합니다.

## 성능 요구사항 (요구사항 기준)
- **실시간성**: 주문 발생 후 관리자 화면에 **2초 이내** 표시 (SSE)
- **규모**: 다중 매장 지원, 매장당 50개 이상 테이블

## 비고: MVP 환경 제약
- 현재 데이터 저장소는 **SQLite**로, 대규모 동시 쓰기에는 제약이 있습니다(로컬 개발 우선 결정).
- 프로덕션 대규모 운영 시 PostgreSQL 등으로 전환 후 본격 부하 테스트를 권장합니다.

## 실시간성(SSE) 수동 검증
1. 관리자 대시보드를 연다(브라우저 A): `/admin/dashboard`
2. 고객 화면에서 주문을 생성한다(브라우저 B)
3. 대시보드 카드가 강조되며 주문이 표시되는 시간을 측정 → **2초 이내** 기대

## 부하 테스트 (도입 시 권장)
프로덕션 전 검증 시 k6 또는 autocannon 사용을 권장합니다.
```bash
# 예: autocannon으로 메뉴 조회 부하
npx autocannon -c 50 -d 20 http://localhost:3001/api/stores/store-001/menu
```
- 측정 지표: 응답시간(p95), 처리량(req/s), 에러율
- 주문 생성 부하는 동일 세션 동시 쓰기 시 SQLite 잠금 영향 확인

## 현재 상태
- MVP 단계로 본격 부하 테스트는 미수행. 실시간성은 로컬 수동 검증으로 2초 이내 확인.
- 대규모 부하 검증은 프로덕션 DB 전환 후 Operations 단계에서 수행 권장.
