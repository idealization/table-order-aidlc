# 비즈니스 규칙 (Business Rules) — Unit: table-order

검증 규칙, 제약, 정책을 정의합니다. 각 규칙은 ID로 추적합니다.

---

## 인증 / 세션 규칙

| ID | 규칙 |
|----|------|
| BR-AUTH-1 | 테이블 로그인은 (storeId, tableId, password)가 모두 일치해야 성공한다. |
| BR-AUTH-2 | 관리자 인증 성공 시 JWT 토큰을 발급하며 만료는 16시간이다. |
| BR-AUTH-3 | 만료/무효 토큰으로 보호 라우트 접근 시 401을 반환한다. |
| BR-SESS-1 | 한 테이블에 활성 세션은 최대 1개만 존재한다. |
| BR-SESS-2 | 로그인 시 활성 세션이 있으면 재사용하고, 없으면 새로 생성한다. (Q2=B) |
| BR-SESS-3 | 이용 완료 처리 시 세션은 비활성(is_active=false)되고 ended_at이 기록된다. |

## 주문 규칙

| ID | 규칙 |
|----|------|
| BR-ORD-1 | 주문은 1개 이상의 항목을 포함해야 한다. 빈 주문은 거부(400). (Q6=A) |
| BR-ORD-2 | 각 주문 항목의 수량은 1 이상이어야 한다. |
| BR-ORD-3 | 주문번호는 매장 전체에서 순차 증가한다. (Q1=A) |
| BR-ORD-4 | 주문 총액은 Σ(단가×수량)으로 계산되며 정수(원)이다. |
| BR-ORD-5 | 주문 생성은 유효한 활성 세션에서만 가능하다. |
| BR-ORD-6 | 주문 항목의 메뉴명·단가는 주문 시점 값으로 스냅샷 저장된다. (Q5=A) |
| BR-ORD-7 | 주문 상태는 pending/preparing/completed 중 하나만 유효하며, 자유 전환이 허용된다. (Q3=B) |
| BR-ORD-8 | 주문 생성 성공 시 매장 관리자에게 실시간(SSE) 통지한다. |
| BR-ORD-9 | 주문 생성 실패 시 트랜잭션을 롤백하고 클라이언트 장바구니는 유지한다. |

## 메뉴 규칙

| ID | 규칙 |
|----|------|
| BR-MENU-1 | 메뉴 등록 시 name, price, category_id는 필수이다. |
| BR-MENU-2 | 가격은 0 이상 정수만 허용한다(무료 메뉴 가능). (Q4=B) |
| BR-MENU-3 | is_available=false 메뉴는 고객 메뉴 조회에서 제외된다. |
| BR-MENU-4 | 메뉴는 sort_order 오름차순으로 노출된다. |
| BR-MENU-5 | 메뉴 삭제/수정은 과거 주문 이력에 영향을 주지 않는다(스냅샷). (Q5=A) |
| BR-MENU-6 | 이미지는 로컬 파일 업로드로 저장하고 경로를 image_url에 기록한다. |

## 테이블 / 이용 완료 규칙

| ID | 규칙 |
|----|------|
| BR-TBL-1 | (store_id, table_number)는 유일해야 한다. |
| BR-TBL-2 | 이용 완료 시 해당 세션 주문은 OrderHistory로 이동 후 원본 삭제된다. |
| BR-TBL-3 | 이용 완료 후 테이블의 현재 주문/총액은 0으로 표시된다. |
| BR-TBL-4 | OrderHistory에는 원 주문 시각(created_at)과 이용 완료 시각(archived_at)을 함께 기록한다. |

## 조회 / 표시 규칙

| ID | 규칙 |
|----|------|
| BR-VIEW-1 | 고객 주문 내역은 현재 세션 주문만, 시간 역순으로 표시한다. |
| BR-VIEW-2 | 관리자 대시보드 테이블 카드는 최신 주문 5개를 미리보기로 표시한다. (Q7=C) |
| BR-VIEW-3 | 신규 주문 도착 시 해당 테이블 카드를 시각적으로 강조한다. |
| BR-VIEW-4 | 과거 내역은 시간 역순 정렬하며 날짜 필터를 지원한다. |
| BR-VIEW-5 | 신규 주문은 발생 후 2초 이내 관리자 화면에 표시되어야 한다. |

## 검증 실패 처리 정책 (Error Handling)

| 상황 | 응답 |
|------|------|
| 빈 주문 / 잘못된 수량 | 400 Bad Request |
| 무효 세션으로 주문 | 400 Bad Request |
| 잘못된 상태 값 | 400 Bad Request |
| 존재하지 않는 리소스 | 404 Not Found |
| 인증 실패 / 토큰 무효 | 401 Unauthorized |
| 서버 내부 오류 | 500 + 트랜잭션 롤백 |
