# 페르소나 (Personas)

테이블오더 서비스의 핵심 사용자 유형을 상세 페르소나로 정의합니다.

---

## 페르소나 1: 김지은 — 고객 (주문자)

![Customer Persona](placeholder)

| 항목 | 내용 |
|------|------|
| **이름** | 김지은 |
| **나이** | 32세 |
| **직업** | 회사원 (마케팅 담당) |
| **기술 친숙도** | 높음 — 스마트폰/태블릿 일상 사용, 키오스크·배달앱에 익숙 |
| **이용 상황** | 동료 3명과 점심 식사, 빠르게 주문하고 대화에 집중하고 싶음 |

### 목표 (Goals)
- 직원을 부르지 않고 바로 메뉴를 보고 주문하고 싶다
- 음식 사진과 설명을 보고 메뉴를 고르고 싶다
- 추가 주문을 쉽게 하고, 지금까지 주문한 내역과 총액을 확인하고 싶다

### 불만사항 (Pain Points)
- 바쁜 시간대에 직원을 불러도 잘 오지 않아 기다리는 것이 답답하다
- 종이 메뉴판은 사진이 없어 음식이 어떤지 상상하기 어렵다
- 내가 뭘 주문했는지, 얼마 나왔는지 헷갈린다

### 행동 특성 (Behaviors)
- 터치 인터페이스를 빠르게 조작하며, 직관적이지 않으면 금방 포기한다
- 주문 전에 장바구니에서 수량을 여러 번 조정한다
- 식사 중간에 음료나 추가 메뉴를 주문한다

### 시스템 사용 접점
- 테이블에 비치된 태블릿 (자동 로그인 상태)
- 메뉴 조회 → 장바구니 → 주문 → 주문 내역 확인

## 페르소나 2: 박상철 — 매장 운영자 (관리자)

| 항목 | 내용 |
|------|------|
| **이름** | 박상철 |
| **나이** | 45세 |
| **직업** | 식당 사장 (좌석 40석 규모, 테이블 20개) |
| **기술 친숙도** | 중간 — PC/태블릿 기본 사용 가능, 복잡한 설정은 부담스러워함 |
| **이용 상황** | 점심·저녁 피크 타임에 카운터에서 주문 현황을 한눈에 관리 |

### 목표 (Goals)
- 들어오는 주문을 실시간으로 빠짐없이 확인하고 싶다
- 테이블별로 주문 상태와 총 주문액을 한눈에 파악하고 싶다
- 잘못된 주문을 즉시 수정/삭제하고, 손님이 나가면 테이블을 정리하고 싶다
- 메뉴와 가격을 직접 등록·수정하고 싶다

### 불만사항 (Pain Points)
- 피크 타임에 주문이 몰리면 누락되거나 헷갈린다
- 손님이 바뀌었는데 이전 주문이 남아 있어 정산이 꼬인다
- 종이 주문서는 분실·오기 위험이 크다

### 행동 특성 (Behaviors)
- 카운터 PC 화면을 수시로 확인하며 신규 주문에 즉각 반응한다
- 새 주문은 색상·강조로 빠르게 인지하길 원한다
- 영업 종료 후 과거 주문 내역을 확인해 정산한다

### 시스템 사용 접점
- 관리자 대시보드 (PC/태블릿, JWT 16시간 세션)
- 실시간 주문 모니터링(SSE) → 테이블 관리 → 메뉴 관리

## 페르소나 3: 이수민 — 매장 직원 (서빙/세팅 담당)

| 항목 | 내용 |
|------|------|
| **이름** | 이수민 |
| **나이** | 23세 |
| **직업** | 아르바이트 (홀 서빙) |
| **기술 친숙도** | 높음 — 모바일·태블릿에 매우 익숙 |
| **이용 상황** | 새 손님이 앉으면 테이블 태블릿을 세팅하고, 주문 상태를 확인해 서빙 |

### 목표 (Goals)
- 새 테이블 태블릿을 빠르고 간단하게 초기 설정하고 싶다
- 어떤 주문이 준비 완료되어 서빙해야 하는지 명확히 알고 싶다
- 손님이 나간 테이블을 빠르게 정리(이용 완료)하고 싶다

### 불만사항 (Pain Points)
- 초기 설정이 복잡하면 손님을 기다리게 한다
- 어느 테이블 음식이 나왔는지 헷갈려 서빙이 늦어진다

### 행동 특성 (Behaviors)
- 관리자가 부여한 권한 범위 내에서 대시보드를 빠르게 조작한다
- 주문 상태 변경(준비중→완료)을 자주 사용한다

### 시스템 사용 접점
- 테이블 태블릿 초기 설정 화면
- 관리자 대시보드 (주문 상태 변경, 테이블 이용 완료)

> **참고**: MVP에서는 관리자 계정이 하드코딩된 단일 계정(`requirements.md` 기준)이므로, 이수민은 박상철과 동일한 관리자 계정을 공유하여 사용합니다. 별도의 직원 계정·권한 분리는 향후 확장 범위입니다.
