## 기능 요구사항 (Functional Requirements)

### FR-1: 고객용 기능

#### FR-1.1: 테이블 태블릿 자동 로그인 및 세션 관리
- 관리자가 초기 설정 1회 수행 (매장 식별자, 테이블 번호, 테이블 비밀번호)
- 로그인 정보 로컬 저장 후 자동 로그인
- 16시간 세션 유지

#### FR-1.2: 메뉴 조회 및 탐색
- 메뉴 화면이 기본(홈) 화면
- 카테고리별 메뉴 분류 및 표시
- 메뉴 상세 정보: 메뉴명, 가격, 설명, 이미지
- 카테고리 간 빠른 이동 (탭/네비게이션)
- 카드 형태 레이아웃, 터치 친화적 (최소 44x44px 버튼)

#### FR-1.3: 장바구니 관리
- 메뉴 추가/삭제, 수량 조절
- 총 금액 실시간 계산
- 장바구니 비우기
- 클라이언트 측 로컬 저장 (새로고침 시에도 유지)
- 서버 전송은 주문 확정 시에만

#### FR-1.4: 주문 생성
- 주문 내역 최종 확인 후 확정
- 주문 성공 시: 주문 번호 표시 → 장바구니 비우기 → 5초 후 메뉴 화면 자동 리다이렉트
- 주문 실패 시: 에러 메시지 표시, 장바구니 유지
- 주문 정보: 매장 ID, 테이블 ID, 메뉴 목록(메뉴명, 수량, 단가), 총 금액, 세션 ID

#### FR-1.5: 주문 내역 조회
- 현재 테이블 세션의 주문만 표시
- 주문 시간 순 정렬
- 주문별: 주문 번호, 시각, 메뉴/수량, 금액, 상태(대기중/준비중/완료)
- 매장 이용 완료 처리된 주문 제외

### FR-2: 관리자용 기능

#### FR-2.1: 매장 인증
- 매장 식별자 + 사용자명 + 비밀번호 입력
- JWT 토큰 기반 인증, 16시간 세션 유지
- 브라우저 새로고침 시 세션 유지
- 하드코딩 단일 관리자 계정 (MVP)

#### FR-2.2: 실시간 주문 모니터링
- SSE(Server-Sent Events) 기반 실시간 주문 업데이트
- 그리드/대시보드 레이아웃: 테이블별 카드 형태
- 각 테이블 카드: 총 주문액, 최신 주문 미리보기
- 주문 카드 클릭 시 전체 메뉴 목록 상세 보기
- 주문 상태 변경 (대기중 → 준비중 → 완료)
- 신규 주문 시각적 강조 (색상/애니메이션)
- 2초 이내 주문 표시

#### FR-2.3: 테이블 관리
- **테이블 초기 설정**: 테이블 번호/비밀번호 설정, 세션 생성
- **주문 삭제**: 확인 팝업 → 즉시 삭제 → 총 주문액 재계산
- **테이블 세션 종료(이용 완료)**: 확인 팝업 → 주문 내역 과거 이력 이동 → 현재 주문/총액 리셋
- **과거 주문 내역 조회**: 테이블별 과거 주문 목록 (시간 역순), 날짜 필터링

#### FR-2.4: 메뉴 관리
- 메뉴 CRUD (등록/조회/수정/삭제)
- 메뉴 정보: 메뉴명, 가격, 설명, 카테고리, 이미지 (로컬 업로드)
- 메뉴 노출 순서 조정
- 필수 필드 및 가격 범위 검증

## 비기능 요구사항 (Non-Functional Requirements)

### NFR-1: 성능
- SSE 기반 실시간 통신: 주문 발생 후 2초 이내 관리자 화면 표시
- 다중 매장 지원 (매장당 50개 이상 테이블)
- MVP 단계에서는 SQLite 사용 (추후 PostgreSQL 등으로 전환 가능한 구조)

### NFR-2: 사용성
- 터치 친화적 UI (최소 44x44px 터치 타겟)
- 직관적인 카드 기반 레이아웃
- 명확한 시각적 피드백 (성공/실패/로딩 상태)

### NFR-3: 안정성
- 장바구니 로컬 저장 (새로고침 시 유지)
- 세션 만료 시 자동 로그아웃
- 주문 실패 시 데이터 유지

### NFR-4: 유지보수성
- TypeScript 전체 적용 (타입 안전성)
- 프론트엔드/백엔드 분리된 프로젝트 구조
- RESTful API 설계

## 제외 범위 (Out of Scope)

요구사항 constraints.md에 명시된 항목:
- 결제 처리 (PG사 연동, 영수증, 환불, 포인트/쿠폰)
- 복잡한 인증 (OAuth, SNS, 2FA)
- 이미지 리사이징/최적화, CMS, 광고
- 알림 시스템 (푸시, SMS, 이메일, 소리/진동)
- 주방 기능 (주방 전달, 재고 관리)
- 고급 기능 (분석, 매출 리포트, 재고, 직원 관리, 예약, 리뷰, 다국어)
- 외부 연동 (배달, POS, 소셜, 지도, 번역)

## 데이터 모델 개요

### 핵심 엔티티
- **Store**: 매장 정보 (매장 식별자, 이름)
- **Table**: 테이블 정보 (테이블 번호, 비밀번호, 매장 연결)
- **TableSession**: 테이블 세션 (시작 시각, 종료 시각, 활성 상태)
- **Category**: 메뉴 카테고리 (이름, 순서, 매장 연결)
- **MenuItem**: 메뉴 항목 (이름, 가격, 설명, 이미지 경로, 카테고리 연결, 순서)
- **Order**: 주문 (주문 번호, 테이블, 세션, 상태, 총 금액, 생성 시각)
- **OrderItem**: 주문 항목 (메뉴명, 수량, 단가, 주문 연결)
- **OrderHistory**: 과거 주문 이력 (세션 종료 시 이동)

## MVP 개발 범위 요약

**고객용**: 자동 로그인 → 메뉴 조회 → 장바구니 → 주문 생성 → 주문 내역 조회
**관리자용**: 매장 인증 → 실시간 주문 모니터링(SSE) → 테이블 관리 → 메뉴 관리
